# V4 development plan

1. Validate public API connectivity and authenticated account access.
2. Collect real-time market observations without submitting orders.
3. Observe predictive-model gating and live prediction outcomes.
4. Run controlled test-account trading with orders enabled.
5. Review fills, fees, turnover, and realized account behavior.
6. Tune only from forward/live evidence; keep changes in traceable Git commits.
7. Before competition deployment, switch API URL and namespace to the competition environment, verify account allocation and permissions, then deploy on the AWS VM supplied by the organizers.

Prediction is treated as an empirical research component. It is never assumed to be profitable or risk-free.
