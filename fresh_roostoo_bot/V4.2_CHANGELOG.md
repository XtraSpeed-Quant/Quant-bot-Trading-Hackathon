# Roostoo Quant Engine V4.2.1

## Strategy changes

- Portfolio sizing is now smoother across the selected top assets instead of concentrating as aggressively into the highest score.
- Market strength controls gross exposure continuously rather than using only the previous linear formula.
- Extremely weak markets can force the long target to zero when breadth or market strength falls below explicit defensive thresholds.
- Default live selection uses up to five long candidates with correlation-aware diversification.
- Existing positions can be fully exited when no qualifying target remains; the engine no longer skips a rebalance merely because the signal list is empty.
- The normal 60-second observation loop and 15-minute rebalance cadence remain unchanged.

## Predictor changes

- Fixed the walk-forward validation split so it is relative to the first usable feature timestamp rather than absolute index zero. The previous split could leave the training window empty for a long time even with thousands of pooled samples.
- Predictor gate failures now expose the actual reason in the dashboard.
- Prediction retraining cadence remains configurable.

## Execution/accounting changes

- After a successful order, the engine refreshes the wallet before reporting final equity/exposure for that cycle.
- A new bot session baseline is stored per namespace so the dashboard can distinguish the account's historical P&L from the P&L since the new strategy session began.

## Terminal changes

The dashboard now surfaces the current action, next rebalance countdown, cash, exposure percentage, session P&L, exchange-initial P&L, eligible market count, predictor gate reason, current holdings, signal targets, and order plan.

## V4.2.1 fixes

- A zero strategy target now forces an eligible spot position toward exit even when its dollar size is just below the normal rebalance band.
- The engine now passes the predictor gate reason into the dashboard result.
- Holdings now display the actual strategy target instead of falling back to the current position value when no order-plan row exists.
- Inspection mode preserves the intended action in the headline, for example `INSPECTION ONLY | CASH / NO LONG EXPOSURE`.

## Validation

All 12 automated tests pass in the V4.2.1 source tree.
